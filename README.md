# Maison Étoile — Haute Gastronomie Française

> **An award-winning, cinematic, romantic, and responsive web experience for a luxury French fine-dining restaurant.**

Designed and developed autonomously to deliver editorial-grade UI/UX craftsmanship, bespoke glassmorphism, responsive reflow, accessibility, and robust front-end engineering.

---

## 🌟 Visual Identity & Art Direction

- **Brand Personality:** Romantic, intimate, sophisticated, timeless, cinematic, exclusive, warm, Parisian.
- **Palette:**
  - **Midnight Blue (`#17243B`)**: The foundation of the visual environment.
  - **Deep Navy (`#101827`)**: Rich grounding contrast.
  - **Warm Ivory (`#E8DFD0`)**: Editorial typography and readability.
  - **Muted Silver (`#A5A9B2`)**: Metadata and subdued details.
  - **Muted Plum (`#583B46`)**: Warm undertones and ambient vignettes.
  - **Candlelight Gold (`#C8A878`)**: Spacing rules, stars, borders, and CTA highlights.
- **Typography:**
  - Headings & Accents: **Cormorant Garamond** (French editorial serif).
  - Body & UI Controls: **Montserrat** (Refined geometric sans-serif).

---

## 🚀 Key Features

1. **Cinematic Hero:**
   - Exact headline: `EXQUISITE CUISINE, TIMELESS MOMENTS`.
   - Signature glassmorphism capsule button: `EXPLORE THE MENU` with authentic backdrop blur, translucent ivory border, and specular highlight.
   - High-resolution fine-dining photography depicting sommelier decanter, chef tweezers garnish, and candlelight bokeh.
2. **Our Story:**
   - Balanced editorial composition celebrating culinary heritage, artisan terroir partnerships, and Parisian dining philosophy.
3. **Menu Preview & Signature Dishes:**
   - 4 Featured dishes: *Velouté de Champignons* (€28), *Filet de Bar Sauvage* (€32), *Bœuf Bourguignon de Charolais* (€30), and *Tarte Tatin Caramélisée* (€14).
   - Category filtering (Créations Signature, Entrées, Plats, Desserts).
   - Interactive Sommelier Pairing notes and dietary tags.
4. **Dining Experience:**
   - 3 Curated experiential pillars: *Fine Dining*, *Wine & Pairing (700+ Grands Crus)*, and *Private Dining (Salons Particuliers)* with detail drawers.
5. **Interactive Editorial Gallery & Lightbox:**
   - Full keyboard accessibility (Arrow Left/Right, Escape), focus trapping, and screen reader announcements.
6. **Reservation Booking Engine (Honest Demo Mode):**
   - Live client-side validation, guest counts (1–8), seating ambiance preferences, dietary/accessibility requests.
   - Clear and transparent demo designation without capturing sensitive payment data.
7. **Legal & Compliance Starter Suite:**
   - Modal and markdown policies covering Privacy (GDPR draft), Cookie Policy, Terms of Use, Reservation Policy, and Accessibility Statement (WCAG 2.2 AA).

## 🛠️ Stack & Architecture

- **Runtimes & Tooling:** Node.js v20+, Vite 6, TypeScript 5+, React 19.
- **Icons:** Lucide React & Handcrafted Luxury Brand SVGs.
- **Styling:** Modular CSS Tokens (`src/styles/variables.css` & `src/styles/global.css`) with zero runtime styling overhead.
- **Tests:** Native Node Test Runner (`node --test`) validating assets, tokens, copy, and forms.

## 🏃 Quick Start Guide

### Prerequisites
- Node.js (v18.0.0 or higher) and npm installed.

### Installation & Running
```bash
# 1. Clone or navigate to the workspace
cd c:/Users/Hp/Desktop/Maison-Etoile

# 2. Install dependencies (if not already cached)
npm install

# 3. Start development server
npm run dev

# 4. Or build and preview production bundle
npm run build
npm run preview
```

### Running Automated Verification Tests
```bash
npm test
```
